# hackaton_Specialist_Appointment_Scheduling_Waitlist-
Specialist Appointment Scheduling &amp; Waitlist​ - Hackaton
High-demand specialty appointments are still managed by phone and manual
waitlists spanning weeks. Patients have no visibility into their position, and
scheduling staff spend significant time on coordination calls.

Acceptance criteria: a patient can see their waitlist position and receive an
update when a slot opens — without calling the office.​​
